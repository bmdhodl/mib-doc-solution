# Organizer submission checklist

Deadline: **August 3, 2026 at 11:59 p.m. Pacific Time**.

Both the pull request and submission form are required.

1. Publish this solution repository at:
   `https://github.com/bmdhodl/mib-doc-solution`
2. Build and run the exact Docker image on all 5,000 validation PDFs.
3. Validate `predictions.jsonl` against `data/validation_manifest.csv` with
   `--require-complete`.
4. Fork `8090-inc/mib-doc-challenge`.
5. In the fork, add only:

   ```text
   submissions/bmdhodl/
   ├── predictions.jsonl
   ├── MEMO.md
   └── SUBMISSION.md
   ```

6. Complete the organizer's form:
   <https://docs.google.com/forms/d/1ZLkHmTsYd9I87JL1sUyps2rPTe6ohEI_lTZ8Jjts6bw/viewform>
7. Open a pull request from the fork to
   `8090-inc/mib-doc-challenge:main`.
8. Confirm the PR changes no file outside
   `submissions/bmdhodl/`.
9. Record the solution commit, Docker image digest, validation prediction
   SHA-256, row count, and validator output in the PR.

Do not copy another participant's validation predictions. The JSONL in the
organizer PR must be generated by the exact public solution commit linked from
`SUBMISSION.md`.
